# AT Grafana 0.1.0 — Release notes & acceptance record

**Date:** 2026-07-30
**Status:** V1 feature-complete (Phases 0–8 of the [implementation plan](../plans/2026-07-29-at-grafana-v1-implementation-plan.md)); **not yet fully verified against a live Grafana instance or a real MCP client** — see "Pending manual verification" below.

This document is the canonical acceptance record for the first release. It scores the project against the 10 Definition-of-Done items in [`docs/requirements.md` §7](../requirements.md#7-验收标准definition-of-done-方向), citing the specific automated test(s) backing each claim, and is explicit about what still needs a human with a real Grafana instance and a real MCP client to close out.

## GitHub Release highlights

First public release of **AT Grafana** — Grafana dashboards, Unified Alerting, and read-only Agent (MCP) access inside VS Code / Cursor.

### Install

1. Download `at-grafana-0.1.0.vsix` from this release (or build with `npm run package`).
2. VS Code / Cursor → **Extensions → ⋯ → Install from VSIX…**
3. Open the **AT Grafana** activity bar → **Add Instance**

### What's included

- Multi-instance Grafana config (Service Account Token in `SecretStorage`) with TLS Trust-On-First-Use
- Dashboards / Alerts sidebar trees (folder grouping, title filter, Firing-first sort)
- Native interactive dashboard & alert Webviews via a local `127.0.0.1` embed proxy (token never exposed to the Webview)
- Pre-flight TLS trust prompt before opening an embedded page
- 9 read-only MCP tools on the shared AT Series Hub (`grafana_list_*` / `grafana_get_*` / `grafana_query_datasource`)
- Per-instance **Allow background Agent access** gate (default off)
- Agent skill: [`skills/at-grafana-mcp`](../../skills/at-grafana-mcp/SKILL.md)

### Not in 0.1.0

- Single-panel drill-down, Legacy Alerting, write/mute/pause operations, multi-org, Grafana Live WebSocket through the embed proxy

## Residual risks

1. `getAlertRuleHistory` response shape not validated against a live Grafana instance.
2. Embed proxy HTML/JS/CSS rewriting is regex-based; highest practical risk vs real Grafana builds.
3. Dashboard/alert URL schemes built from docs/API shape, not live page confirmation.
4. Query limit defaults (12h / 5 MiB) are proposed, not calibrated.
5. No WebSocket / Grafana Live proxying in V1.

## What's new in 0.1.0

First release. Full V1 feature set per [`docs/requirements.md`](../requirements.md):

- Multi-instance Grafana configuration with Service Account Token auth (SecretStorage-backed) and TLS Trust-On-First-Use
- Dashboard and alert-rule tree views in the sidebar (folder-grouped, filterable, Firing-sorted)
- Native dashboard/alert Webview panels via a local `127.0.0.1` reverse proxy that injects the `Authorization` header server-side
- TLS trust pre-flight before opening embedded pages (`ensureGrafanaTlsTrust`)
- A 9-tool `at.grafana` MCP catalog (all `risk: read`), gated by per-instance background access, on the shared AT Series Hub
- Bilingual docs + `skills/at-grafana-mcp`

See [`docs/plans/2026-07-29-at-grafana-v1-implementation-plan.md`](../plans/2026-07-29-at-grafana-v1-implementation-plan.md) for the full phase-by-phase implementation history.
