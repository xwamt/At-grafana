# AT Grafana 0.1.1 Release Notes

Version 0.1.1 introduces significant security hardening, server-side payload projection, local embed reverse proxy isolation, query rate limiting, and API pagination resilience.

## Highlights & New Features

### 1. Dashboard Field Projection (Context Optimization)
- **Server-Side Field Projection**: `grafana_get_dashboard` adds the `fields` parameter (`full`, `summary`, `targets`).
  - `targets` extracts only metric query expressions (`expr`, `refId`) and datasource UIDs, stripping heavy UI layout and panel configurations to reduce LLM context token usage by 66% to 85%.
  - `summary` returns an inventory of panel IDs, titles, types, and datasource configurations.
- **Panel ID & Title Filtering**: Supports `panelIds` (array of numbers) and `titleContains` (case-insensitive substring) to isolate specific panels or nested row panels directly on the server side.

### 2. Local Reverse Proxy & CSP Security
- **Dynamic Local Embed Proxy**: Rewrites embedded dashboard and alert panel iframes via an ephemeral 127.0.0.1 reverse proxy (`/e/:embedToken/...`).
- **Anti-DNS Rebinding Defense**: Validates that incoming `Host` headers strictly point to loopback authorities and enforces Origin matching. Rejects invalid tokens with a silent HTTP 404 to resist local port scanning.
- **Strict Content Security Policy (CSP)**: Strips upstream CSP headers and re-issues a restrictive CSP isolating iframe rendering from external networks.
- **Datasource Subtree Confinement**: Restricts datasource proxy routes strictly to their assigned subpaths to prevent path traversal vulnerabilities.

### 3. Query Rate Limiting & Cost Metering
- **Per-Instance Token-Bucket Rate Limiter**: Enforces query rate limits (`QueryRateLimiter`) to prevent aggressive polling from triggering Grafana upstream rate limiting or DDoS defenses.
- **Query Cost Metering**: Measures agent query complexity against configured instance query limits.

### 4. API Resilience & Pagination
- **Search & Alert Tree Pagination**: Implements full cursor/page iteration for Grafana dashboard search and alert rule folder lookups.
- **Idempotent Read Retries**: Adds network error classification and automatic retry policies for GET/HEAD requests.
- **Folder UID Compatibility**: Seamlessly normalizes differences between `folderUid` and `folderUID` across Grafana versions.

### 5. Extension Lifecycle & Memory Safety
- **Subscription Leak Fix**: Cleanly disposes of async webview panel listeners and prevents unbounded `context.subscriptions` growth.
- **Pre-Buffer Bridge Authentication**: Enforces constant-time token comparison (`timingSafeEqualToken`) and rejects unauthorized HTTP requests prior to buffering request payloads.
