# AT Grafana 0.1.2 Release Notes

Version 0.1.2 brings complete internationalization (i18n / l10n) support to the AT Grafana extension, supporting seamless bilingual (English / Simplified Chinese) switching across configuration forms, dashboard panels, alert views, and interactive certificate verification.

## Highlights & New Features

### 1. VS Code Native Internationalization & Localization (l10n)
- **Standard `vscode.l10n` Infrastructure**: Implemented lightweight `t()` helper utilizing VS Code's official localization runtime with parameter substitution and fallback support.
- **Bilingual Manifest Localization**: Migrated all view titles, commands, and settings descriptions in `package.json` to `%atGrafana...%` NLS tokens supported by `package.nls.json` and `package.nls.zh-cn.json`.
- **Runtime Localization Bundles**: Added runtime localization bundle `l10n/bundle.l10n.zh-cn.json` for live UI language adaptation.

### 2. Webview & Instance Form Localization
- **Grafana Instance Form (`GrafanaInstanceFormPanel`)**: Fully localized all input fields (label, URL, Service Account Token, and the "Allow background Agent access" toggle), form validations, and feedback prompts.
- **Interactive Connection Verification**: Localized connection test status indicators, latency feedback, and error diagnosis banners.
- **Dashboard & Alert Webview Panels**: Localized iframe container loading overlays, refresh triggers, and error messages in `DashboardPanel` and `AlertDetailPanel`.

### 3. Tree Providers & Security Prompts
- **Dashboard & Alert Rule Trees**: Localized folder items, search results, alert status badges, and context actions in `DashboardTreeProvider` and `AlertTreeProvider`.
- **Interactive Certificate Verification**: Localized untrusted/self-signed SSL certificate prompts and fingerprint confirmation dialogs in `createInteractiveCertVerifier`.

### 4. Build, Packaging & Quality Assurance
- **Package Script Enhancement**: Updated `scripts/package.mjs` to automatically bundle NLS resource files into the VSIX distribution package.
- **Automated Localization Testing**: Added dedicated i18n test suites (`test/i18n/nls.test.ts`, `test/i18n/t.test.ts`) covering all 478 unit and integration tests.
