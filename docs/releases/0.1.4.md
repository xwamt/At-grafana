# AT Grafana 0.1.4 Release Notes

Version 0.1.4 brings critical network reliability fixes (AWS WAF User-Agent header and HTTPS keep-alive TOFU handshake fixes), Webview embedded proxy caching and performance optimizations, MCP alerting and deeplink completeness enhancements, and upgrades `@at-series/mcp-hub` to **0.3.3**.

## Highlights & New Features

### 1. Network & TLS Connection Reliability (P0)
- **User-Agent Header Support**: Added `User-Agent: AT-Grafana/1.0` to `GrafanaHttpClient` and `testGrafanaConnection` requests, preventing AWS WAF (e.g. `NoUserAgent_HEADER` rule) and cloud reverse proxy gateways from dropping health check and API calls.
- **HTTPS Keep-Alive TOFU Socket Fix (PERF-01)**: Resolved a 15-second timeout on reused HTTPS sockets under Node.js keep-alive pooling by verifying synchronously readable peer certs instead of waiting for deferred `secureConnect` events.
- **Actionable TLS Recovery Hint (UX-08)**: When certificate fingerprint verification fails or is unconfirmed, Agent-facing tool errors and sidebar UI now provide a clear prompt guiding users to confirm the TLS fingerprint in the AT Grafana sidebar.

### 2. Webview Embedded Proxy Performance & UX (PERF & UX)
- **Credential & ETag LRU Caching (PERF-02 / PERF-03)**: Added in-memory credential caching and ETag rewrite LRU caching to `GrafanaEmbedProxy`, eliminating redundant upstream token queries and compute overhead.
- **Proxy Idle Auto-Shutdown (PERF-11)**: Embedded reverse proxies automatically shut down when Webview panels close or remain idle, freeing local port and memory resources.
- **Webview Loading & Error Experience (UX-12)**: Added loading spinners, language attributes, and styled proxy error diagnostics pages for embedded dashboards and alert panels.

### 3. MCP Alerting & Deeplink Completeness (FUNC & UX)
- **Alert Rule Provisioning Data (FUNC-01 / FUNC-09)**: `grafana_get_alert_rule` now directly queries `GET /api/v1/provisioning/alert-rules/:uid` with full query models (`AlertQuery[]`) and notification settings; `grafana_list_alert_rules` adds `isPaused` projection.
- **Alert History Time Window (FUNC-04)**: `grafana_get_alert_history` now supports `from`, `to`, and `limit` window filtering, along with diagnostics when Loki-backed alert state history is disabled.
- **Deeplink Kinds & Explore Expressions (FUNC-13)**: `grafana_generate_deeplink` adds `kind: "alertRule"` support and Explore query expression seeds.
- **Instance Enablement Hints (UX-15)**: `grafana_list_instances` returns actionable guidance when no instances are configured or background Agent access is toggled off.

### 4. AT Series MCP Hub 0.3.3 Upgrade & SuperOps Alignment
- **MCP Hub 0.3.3**: Upgraded `@at-series/mcp-hub` to `^0.3.3` with optimized bridge registry polling, directory fingerprint snapshots, and concurrent candidate parsing.
- **SuperOps Discovery Standards**: Aligned `at-grafana-mcp` skill with the `super-ops` hub workflow, clarifying tool discovery and reference cap conventions.
